## Features
- Laravel Framework
- Contact form page
- Responsive design

## How to run this project

1. Clone the repository
   git clone https://github.com/Evel454/myapp.git

2. Go into folder
   cd myapp

3. Install dependencies
   composer install
   npm install

4. Create env file
   cp .env.example .env
   php artisan key:generate

5. Run server
   php artisan serve
